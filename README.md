# 🍽️ Zomato Data Analysis Project

This project performs **Exploratory Data Analysis (EDA)** on Zomato restaurant data using Python libraries like Pandas, Matplotlib, and Seaborn.
The goal of this project is to analyze restaurant trends, customer preferences, ratings, online ordering patterns, and spending behavior.

---

## 📌 Project Objectives

* Analyze different types of restaurants listed on Zomato
* Understand customer voting and rating patterns
* Compare online vs offline ordering trends
* Identify average spending preferences of customers
* Visualize insights using charts and heatmaps

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📂 Dataset

The dataset used in this project contains information about:

* Restaurant types
* Ratings
* Votes
* Approximate cost
* Online order availability
* Table booking
* Customer preferences

---

## 📊 Analysis Performed

### ✅ Data Cleaning

* Converted restaurant ratings into float values
* Checked and handled data types
* Prepared data for visualization

### ✅ Exploratory Data Analysis

Some major business questions answered in this project:

1. Which type of restaurant receives the highest number of customers?
2. Which restaurant category gets the maximum votes?
3. What ratings do most restaurants receive?
4. What is the average spending preference of couples?
5. Which ordering mode receives better ratings?
6. Which restaurant types receive more offline orders?

---

## 📈 Visualizations Used

* Count Plots
* Line Charts
* Histograms
* Box Plots
* Heatmaps

These visualizations help in understanding customer behavior and restaurant performance more effectively.

---

## 🔍 Key Insights

* Dining restaurants are the most common restaurant type.
* Dining restaurants receive the highest number of votes.
* Most restaurants have ratings between **3.5 and 4.0**.
* Couples generally prefer restaurants with an average cost around **₹300**.
* Online orders tend to receive better ratings compared to offline orders.
* Dining restaurants mostly receive offline orders, while cafes receive more online orders.
